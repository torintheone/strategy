# ТЗ для Claude Code: «Politeconomy» — глобальный политико-экономический симулятор для ПК

Oct 28, 2026 · @Pony

## Концепция и рамки

«Politeconomy» — глобальный симулятор государства для ПК по мотивам Geopolitical Simulator 5, с классовой моделью общества в духе Victoria 3. Игрок управляет одной страной из \~190: экономикой, бюджетом, социальной сферой, инфраструктурой, наукой, законами, выборами и дипломатией. Остальными странами управляет ИИ.

Главная идея: каждое решение проходит через классы. Закон или бюджет меняет доходы и интересы конкретных групп населения, а они отвечают голосованием, протестами или поддержкой. Цифры в игре не прописаны сценарием, а получаются из модели.

**Параметры:**

- Старт — 1 января 2026 года (дата старта — один параметр в `data/scenario.json`); стартовое состояние стран берётся из реальных открытых данных последних лет.
- Шаг времени — день (новости, протесты, решения), экономика и демография считаются помесячно, выборы и исследования — по своим срокам. Скорость 1–5 и пауза.
- Партия без ограничения по времени. Дополнительно — сценарии с целью: «удвоить ВВП на душу населения за 15 лет», «выиграть выборы», «пережить долговой кризис».
- Страны настоящие; политики, партии и министры вымышленные, их имена генерируются под культуру страны. Реальные политические системы упрощены до типов (раздел «Власть»).

**Правовые рамки:** механики GS5 и Victoria 3 авторским правом не защищены, но их тексты, интерфейс, графику и названия не копировать. Графика, звук и музыка — только свои, со свободными лицензиями (CC0, CC BY), из общественного достояния или сгенерированные пользователем (раздел «Интерфейс и графика»).

**Вне рамок версии 1:** регионы внутри стран (губернаторы, региональные бюджеты), отдельные компании как объекты, тактическая военная система, мультиплеер. Контент хранится в открытых JSON-файлах, поэтому моды возможны с самого начала.

## Архитектура и техника

Симуляция — отдельная библиотека на C# без зависимости от движка: её можно гонять без графики на 50 лет вперёд, тестировать и балансировать. Godot отвечает только за карту, интерфейс, звук и ввод.

| Слой | Решение |
| --- | --- |
| Движок | Godot 4 (сборка .NET, последняя стабильная 4.x), C# на .NET 8 |
| Ядро симуляции | Библиотека `Politeconomy.Sim`, без `using Godot` |
| Тесты | `Politeconomy.Sim.Tests` на xUnit |
| Инструменты | `Politeconomy.Tools` — консольная программа: прогоны без графики, отчёты баланса, проверка данных |
| Данные | `data/*.json` — страны, отрасли, законы, технологии, события, имена; Python-скрипты в `tools/` собирают их из открытых источников |
| Сохранения | Сериализация мира в JSON + gzip; автосохранение раз в игровой месяц |
| Потоки | Симуляция в фоновом потоке, интерфейс читает снимок состояния |
| Платформа | Windows 10/11 64-bit; рендерер Forward+, запасной — Compatibility |

Структура репозитория:

```
src/Politeconomy.Sim/         — модель мира и системы
src/Politeconomy.Sim.Tests/   — тесты
src/Politeconomy.Tools/       — прогоны, баланс, проверки
game/                         — проект Godot: карта, экраны, звук
data/                         — контент в JSON
tools/                        — скрипты сборки данных (Python)
art/incoming/                 — картинки от пользователя (портреты и др.)
SPEC.md  MODEL.md  DECISIONS.md  CHANGELOG.md  LICENSES-ASSETS.md
```

**Порядок систем в шаге:** экономика → рынок труда → цены и инфляция → бюджет → демография → социальная сфера → политика → дипломатия → решения ИИ → события. Порядок фиксирован и описан в `MODEL.md`; там же — все формулы со ссылками на разделы этого ТЗ.

**Детерминизм:** одинаковый seed и одинаковые решения дают одинаковую партию. Это нужно для тестов и поиска ошибок баланса.

**Производительность:** месячный шаг на 190 стран — не дольше 200 мс, дневной — не дольше 10 мс; карта и меню — 60 кадров/с на игровом ПК.

**Сборка:** GitHub Actions на каждый push запускает тесты, на тег `v*` собирает Windows-версию через Godot без графики и выкладывает zip в GitHub Releases. Подпись кода не нужна; в README предупредить, что Windows SmartScreen может спросить подтверждение при первом запуске.

## Мир, время, данные

В мире \~190 стран — члены ООН; зависимые территории входят в состав метрополий. Все страны живут по одной модели, различаются только данными.

**Источники данных** (скрипт `tools/build_world.py` скачивает их один раз; результат лежит в репозитории, игре интернет не нужен):

| Что | Источник | Лицензия |
| --- | --- | --- |
| Границы стран | Natural Earth 1:50m | Общественное достояние |
| Население, ВВП, отрасли, бюджет, долг, безработица, неравенство, торговля | Всемирный банк, World Development Indicators | CC BY 4.0 |
| Половозрастная структура, рождаемость, смертность, миграция | ООН, World Population Prospects | CC BY 3.0 IGO |
| Энергетика, образование, здравоохранение | Our World in Data | CC BY 4.0 |
| Занятость по отраслям | МОТ (ILOSTAT) | Проверить условия; указать в титрах |
| Тип политической системы | Ручная классификация в `data/politics.json`: Claude Code составляет черновик, пользователь проверяет | — |

Пропуски в данных заполняются средними по региону мира и группе дохода; каждое такое заполнение помечается в файле. Все лицензии — в `LICENSES-ASSETS.md` и на экране титров.

**Разогрев:** перед началом партии модель скрыто прогоняется 24 месяца, чтобы показатели «устоялись» и в первый игровой день не было скачков. После разогрева ключевые показатели (ВВП, инфляция, безработица, долг) не должны отличаться от стартовых данных больше чем на 10%.

**Календарь:**

- Каждый день — новости, события, протесты, исполнение решений.
- Каждый месяц — экономика, рынок труда, цены, бюджет, демография, социальная сфера, решения ИИ.
- Каждый год — бюджетный цикл: проект бюджета осенью, голосование парламента, исполнение с 1 января.
- По конституции — выборы, референдумы, сроки полномочий.
- Исследования и стройки идут непрерывно со своими сроками.

## Экономика

Экономика страны — около 20 отраслей, которые покупают друг у друга сырьё и услуги, нанимают работников разной квалификации и продают продукцию дома и за рубежом. Прибыль отрасли делится между государством, отечественными и иностранными владельцами, и это прямо определяет доходы классов.

**Отрасли:** сельское хозяйство; нефть и газ; уголь и руды; пищевая промышленность; лёгкая промышленность; химия и нефтепереработка; металлургия; машиностроение; электроника и высокие технологии; фармацевтика; оборонная промышленность; строительство; торговля; транспорт и логистика; финансы; ИТ и связь; туризм; образование; здравоохранение; госуправление. Электрогенерация описана в разделе «Инфраструктура и энергетика».

**Производство отрасли** (месячный шаг):

- Выпуск = производительность × капитал^α × эффективный труд^(1−α), затем умножается на коэффициент обеспеченности инфраструктурой и энергией (не больше 1). Нехватка электричества или дорог прямо режет выпуск.
- Эффективный труд — сумма работников по трём уровням квалификации (без образования, профессиональное, высшее) с весами, разными для отраслей.
- Производительность зависит от технологического уровня отрасли (раздел «Наука») и качества институтов: коррупция и слабое право её снижают.
- Межотраслевые закупки — упрощённая таблица «затраты — выпуск» на 20×20: машиностроению нужен металл и энергия, пищевой промышленности — сельское хозяйство. Недостающее покупается по импорту.

**Собственность:** у каждой отрасли доли государства, отечественного частного и иностранного капитала. Прибыль уходит соответственно в бюджет, классу собственников или за рубеж. Национализация и приватизация меняют доли и имеют цену: компенсации, падение инвестиций, реакция групп интересов.

**Инвестиции:** частные — из прибыли и сбережений, зависят от ожидаемой доходности, ставки ЦБ и «делового климата» (налоги, коррупция, стабильность, регулирование). Государственные — из бюджета: госпредприятия и программы. Иностранные — от делового климата, отношений и санкций.

**Рынки и цены:**

| Тип товара | Как образуется цена |
| --- | --- |
| Сырьё (нефть, газ, уголь, металлы, зерно) | Мировая цена по мировому спросу и предложению; крупные экспортёры на неё влияют |
| Промышленные товары | Своя цена в каждой стране; конкурентоспособность — от издержек, производительности и курса валюты |
| Услуги | В основном внутренние цены; туризм — экспортная услуга |

Цена корректируется на долю от разрыва спроса и предложения с ограничением скорости изменения, чтобы не было скачков.

**Рынок труда:** предложение труда по квалификациям — из демографии и образования, спрос — от отраслей. Зарплата по отрасли и квалификации растёт при дефиците работников, а также от минимальной зарплаты и силы профсоюзов. В бедных странах есть неформальный сектор, который поглощает часть безработицы ценой низких доходов.

**Внешняя торговля:** двусторонние потоки по гравитационной модели (размер экономик, расстояние) с поправками на пошлины, торговые соглашения, санкции и курс. Структура экспорта следует сравнительным преимуществам — производительности отрасли относительно мира. Торговый баланс и потоки капитала давят на курс валюты.

**Теневая экономика:** её доля растёт от высоких налогов, коррупции и слабого контроля и снижает собираемость налогов.

## Финансы

Бюджет — главный инструмент игрока: каждая статья доходов и расходов связана с конкретными классами и отраслями. Дефицит можно покрыть долгом или печатанием денег, но у каждого способа своя цена.

**Доходы бюджета:**

| Налог или источник | Настройка | Кого затрагивает |
| --- | --- | --- |
| Налог на доходы физлиц | До 5 ступеней прогрессивной шкалы | Все классы по уровню дохода |
| Налог на прибыль | Ставка, льготы отраслям | Собственники, инвестиции |
| НДС | Основная и льготная ставки | Потребление, бедные классы сильнее |
| Социальные взносы | Ставка на фонд оплаты труда | Работники и работодатели |
| Акцизы | Алкоголь, табак, топливо | Потребление, здоровье |
| Природная рента | Ставка на добычу | Сырьевые отрасли |
| Налог на имущество и богатство | Ставка, порог | Верхние классы |
| Таможенные пошлины | По группам товаров и странам | Импорт, торговые отношения |
| Доходы госпредприятий | Доля прибыли в бюджет | Государственный сектор |

**Расходы** — по ведомствам: пенсии и пособия, здравоохранение, образование, наука, транспорт и инфраструктура, энергетика, сельское хозяйство, промышленная политика, оборона, полиция и безопасность, суды, госаппарат, культура и спорт, внешняя политика, обслуживание долга.

**Бюджетный цикл:** проект бюджета осенью, голосование в парламенте (может провалиться — раздел «Политика»), исполнение с 1 января. Поправки в течение года — тоже через парламент. При авторитарной системе парламент формален.

**Покрытие дефицита:**

- Внутренние облигации — вытесняют частные инвестиции.
- Внешние облигации — валютный риск.
- Кредит международного фонда (вымышленный «Международный валютный совет») — дешевле, но с условиями: урезать расходы, приватизировать.
- Суверенный фонд — копится из природной ренты.
- Эмиссия центробанка — быстро, но разгоняет инфляцию; возможна только при зависимом ЦБ.

**Долг и рейтинг:** ставка по долгу = мировая базовая ставка + премия за риск. Премия растёт с долгом к ВВП, дефицитом, инфляцией и политической нестабильностью. Кредитный рейтинг (от AAA до D) считается формулой. Дефолт — тяжёлое событие: обвал курса, бегство капитала, протесты.

**Центробанк:**

- Независимость задаётся законом. Независимый ЦБ сам ставит ключевую ставку по правилу Тейлора (реакция на инфляцию и разрыв выпуска); зависимым управляет игрок.
- Инфляция = инфляционные ожидания + давление спроса + рост денежной массы сверх выпуска + удорожание импорта из-за курса.
- Режим курса: плавающий, управляемый или фиксированный. Защита фиксированного курса тратит резервы.
- Контроль за движением капитала — отдельный закон.
- Риск банковского кризиса растёт при быстром росте кредита; кризис — событие с выбором: спасать банки, национализировать или дать рухнуть.

На экране бюджета у каждого ползунка видна прогнозная оценка: сколько это даст или отнимет и каким классам.

## Население и классы

Население описано дважды: демографически (возраст, пол, рождаемость, смертность, миграция) и социально — как классы с доходами, потребностями и интересами. Классы — сердце игры: через них экономика превращается в политику.

**Демография** (месячный шаг, годовые коэффициенты делятся на 12):

- Половозрастная структура: пятилетние когорты × пол.
- Рождаемость зависит от доходов, образования женщин, урбанизации, жилья и семейной политики.
- Смертность по возрастам = базовая кривая × качество медицины × доходы × экология × безопасность.
- Урбанизация: переезд из села в город за работой и зарплатой.
- Международная миграция: «выталкивают» безработица, бедность, конфликты и репрессии; «притягивают» зарплаты, миграционный закон и диаспора. Интеграция мигрантов (язык, образование, работа) снижает социальное напряжение.

**Классы:**

| Класс | Источник дохода | Главные интересы |
| --- | --- | --- |
| Безработные | Пособия, случайные заработки | Работа, пособия, цены на еду |
| Неквалифицированные рабочие (вкл. неформальный сектор) | Зарплата | Минимальная зарплата, занятость, жильё, цены |
| Квалифицированные рабочие | Зарплата | Зарплата, профсоюзные права, пенсии, промышленная политика |
| Крестьяне и фермеры | Продажа продукции | Цены на продукцию, субсидии, земля, пошлины |
| Служащие (в т. ч. бюджетники) | Зарплата | Зарплаты в бюджетной сфере, стабильность, медицина, образование |
| Специалисты высшей квалификации | Высокая зарплата | Свобода, низкие налоги на доход, наука, открытость миру |
| Мелкий бизнес и самозанятые | Прибыль | Налоги, регулирование, коррупция, кредиты |
| Крупный капитал | Прибыль, дивиденды | Налог на прибыль, собственность, слабые профсоюзы, свободная торговля или протекционизм — по отрасли |
| Госаппарат и силовики | Зарплата из бюджета, привилегии | Финансирование, статус, порядок |
| Пенсионеры | Пенсии, сбережения | Пенсии, медицина, цены |

**Состояние класса:** численность, доходы, сбережения, уровень образования, здоровье, уровень жизни, удовлетворённость, радикализм, организованность, политические взгляды (раздел «Политика»).

**Потребности** — корзина на трёх уровнях (как в Victoria 3):

- Базовые: еда, жильё, коммунальные услуги, одежда.
- Повседневные: транспорт, связь, медицина, образование детей.
- Престижные: досуг, путешествия, автомобиль, предметы роскоши.

Уровень жизни 0–100 считается по удовлетворению корзины с учётом цен. Ожидания класса медленно подстраиваются под достигнутый уровень, поэтому удовлетворённость реагирует на изменения, а не на абсолютные цифры: рост радует, падение злит, даже если уровень высокий.

**Удовлетворённость класса** = изменение уровня жизни относительно ожиданий + страх безработицы + отношение к действующим законам (каждый закон в данных помечен: каким классам он нравится и насколько) + безопасность + свободы.

**Социальная мобильность** (ежемесячные потоки между классами): образование поднимает детей в квалифицированные классы; безработица опускает вниз; хороший деловой климат рождает мелкий бизнес; приватизация расширяет крупный капитал; рост госаппарата забирает людей в чиновники.

**Влияние класса** = численность × организованность × богатство, с поправкой на политическую систему: при демократии больше весит численность, при авторитаризме — богатство и близость к власти.

## Социальная сфера

Социальные системы — это долгие инвестиции: школа даёт квалифицированных работников через 10–15 лет, профилактика снижает смертность через годы. Игра честно показывает эту задержку, поэтому быстрые популистские решения и долгие реформы по-разному выглядят в коротком и длинном горизонте.

**Образование:**

- Уровни: дошкольное, школьное, профессиональное, высшее. У каждого — охват, качество и доля частного сектора.
- Качество зависит от финансирования на ученика, числа учителей и их зарплаты, состояния зданий, цифровизации.
- Результат: распределение работников по квалификации (с задержкой), грамотность, научный потенциал университетов, социальная мобильность.
- Решения: обязательные годы обучения, платное или бесплатное высшее, бюджетные места и стипендии, зарплаты учителей, профессиональные колледжи под нужды отраслей.

**Здравоохранение:**

- Модель системы: государственная (из бюджета), страховая (обязательное медицинское страхование), частная или смешанная. Модель меняет доступность для разных классов и нагрузку на бюджет.
- Ресурсы: врачи и медсёстры на 1000 жителей (зарплата влияет на число кадров и их отъезд за рубеж), койки, оснащение, высокотехнологичная помощь (кардиохирургия, онкология, трансплантация), сельская медицина, лекарственное обеспечение.
- Результаты: продолжительность жизни, младенческая и материнская смертность, бремя болезней (сердечно-сосудистые, онкологические, инфекционные, травмы), потери производительности из-за болезней.
- Программы: скрининги, вакцинация, борьба с курением и алкоголем (связана с акцизами), развитие высокотехнологичной помощи, медицина на селе.
- Эпидемии — события; их тяжесть зависит от мощности системы и решений игрока.

**Социальная защита:**

- Пенсии: распределительная, накопительная или смешанная система; пенсионный возраст; коэффициент замещения. Старение населения давит на бюджет.
- Пособия по безработице, на детей, по инвалидности, помощь бедным; минимальная зарплата; безусловный базовый доход как отдельный закон.

**Жильё:** жилой фонд на человека, темп строительства (отрасль «Строительство»), цены относительно доходов, социальное жильё, субсидии на ипотеку. Нехватка жилья бьёт по базовым потребностям, рождаемости и удовлетворённости.

**Преступность и коррупция:**

- Преступность растёт от безработицы, бедности, неравенства, доли молодёжи и слабой полиции; организованная преступность — от коррупции и теневой экономики.
- Коррупция — сквозной показатель институтов: снижается от достойных зарплат чиновников, прозрачности, свободы прессы, независимых судов и антикоррупционного органа. Она режет производительность, инвестиции, собираемость налогов и доверие.

**Экология:** загрязнение от промышленности и угольной энергетики повышает смертность и недовольство городских классов; экологические законы снижают его ценой издержек отраслей.

## Инфраструктура и энергетика

Инфраструктура — это пропускная способность экономики: если её не хватает, отрасли упираются в потолок, сколько бы в них ни вкладывали. Каждый объект изнашивается без обслуживания, а строительство занимает годы и потребляет продукцию реальных отраслей.

**Виды инфраструктуры:**

| Вид | Что даёт | Кто нагружает |
| --- | --- | --- |
| Автодороги | Логистика всех отраслей, сельское хозяйство | Вся экономика, население |
| Железные дороги | Сырьё, тяжёлая промышленность, транзит | Добыча, металлургия, экспорт |
| Порты | Морская торговля | Экспорт и импорт |
| Аэропорты | Туризм, деловые поездки | Туризм, услуги |
| Трубопроводы | Экспорт нефти и газа | Нефтегазовая отрасль |
| Электросети | Доставка энергии | Все потребители |
| Связь и интернет | Производительность, ИТ, дистанционное образование | ИТ, услуги, население |
| Водоснабжение и канализация | Здоровье, базовые потребности | Население, пищевая промышленность |

У каждого вида: мощность, загрузка, состояние (износ в год без обслуживания) и стоимость содержания. Коэффициент обеспеченности (мощность ÷ потребность, не больше 1) входит в производство отраслей (раздел «Экономика»).

**Стройки:** проект имеет стоимость, срок и потребности в продукции строительства, металлургии и машиностроения — заказ идёт в эти отрасли. Коррупция удорожает стройку и растягивает сроки. Способы финансирования: бюджет, государственно-частное партнёрство (концессия с платой за пользование), иностранный кредит, который даёт влияние кредитору.

**Энергетика:**

| Тип станции | Плюсы | Минусы |
| --- | --- | --- |
| Угольная | Дёшево строить, стабильно | Загрязнение, выбросы |
| Газовая | Гибкая, быстро строится | Зависит от цены газа |
| Нефтяная (мазут) | Резерв | Дорогое топливо |
| АЭС | Дешёвая стабильная энергия | Дорого и долго строить, нужен уровень технологий, риск аварии |
| ГЭС | Очень дешёвая энергия | Привязана к рекам, долгая стройка |
| Ветер и солнце | Нет топлива и выбросов | Нестабильны, нужны накопители; дешевеют с развитием технологий |

- Спрос на электричество — от отраслей и населения. Дефицит означает веерные отключения: выпуск падает, недовольство растёт.
- Тарифы для населения можно регулировать и субсидировать — ценой бюджета и инвестиций в отрасль.
- Обмен электроэнергией с соседями при наличии межгосударственных линий.
- Энергетическая безопасность: зависимость от импорта топлива — рычаг давления в дипломатии.

## Наука и технологии

Исследования повышают производительность отраслей и открывают новые станции, программы и законы. Есть мировая «граница технологий»: лидеры двигают её дорого, а догоняющие страны осваивают уже известное дешевле. Это даёт реалистичный эффект догоняющего роста.

**Очки исследований в месяц** = расходы на науку (государственные и частные) × эффективность. Эффективность зависит от числа исследователей (класс специалистов высшей квалификации), качества университетов, академической свободы и международного сотрудничества. Утечка мозгов — отъезд специалистов при низких зарплатах и несвободе — её снижает.

**Восемь ветвей** (по 5–8 технологий в каждой, всего \~50):

| Ветвь | Примеры эффектов |
| --- | --- |
| Сельское хозяйство и биотехнологии | Урожайность, засухоустойчивые культуры |
| Промышленность и материалы | Производительность обрабатывающих отраслей, роботизация (выпуск +, спрос на неквалифицированный труд −) |
| Энергетика | Новые типы станций, дешевле ветер и солнце, накопители, малые АЭС |
| ИТ и искусственный интеллект | Производительность услуг, ИТ-экспорт, автоматизация офисного труда |
| Медицина и фармацевтика | Продолжительность жизни, лечение болезней, экспорт лекарств |
| Транспорт | Скоростные железные дороги, электромобили, дешёвая логистика |
| Оборона | Сила армии, экспорт вооружений |
| Государственное управление | Цифровое государство: коррупция −, собираемость налогов +, электронные выборы |

**Механика:**

- Игрок распределяет очки по ветвям в процентах и может выбрать приоритетную технологию.
- Стоимость технологии = базовая цена × множитель «границы»: дешевле, если её уже освоили многие страны, особенно торговые партнёры.
- Распространение технологий идёт через торговлю, иностранные инвестиции и лицензии; санкции его блокируют.
- Некоторые технологии меняют общество: роботизация сокращает спрос на неквалифицированных рабочих и запускает события о безработице и переобучении.
- События: научный прорыв, переманивание учёных, промышленный шпионаж.

## Власть и общественное устройство

Игрок — глава исполнительной власти: президент, премьер или единоличный правитель, в зависимости от системы страны. Возможности игрока ограничены институтами: парламент может провалить закон, суд — отменить решение, элиты — сменить лидера.

**Типы политических систем:** президентская республика, парламентская республика, смешанная, конституционная монархия, абсолютная монархия, однопартийное государство, военный режим. Тип задаёт, кто формирует правительство, сколько весят выборы и как меняется власть.

**Конституционные параметры** (меняются только конституционным законом — квалифицированным большинством или референдумом): сроки и число сроков главы государства, порядок формирования правительства, сила парламента, независимость судов, свобода прессы и собраний, избирательная система, право на референдум, порядок введения чрезвычайного положения.

**Индексы институтов:** демократичность, верховенство права, независимость судов, свобода прессы, гражданские свободы, коррупция, эффективность госаппарата, легитимность власти. Они вычисляются из законов и практики, а не задаются напрямую.

**Правительство** — около 18 постов: министры экономики, финансов, труда и соцзащиты, здравоохранения, образования, науки, транспорта, энергетики, сельского хозяйства, промышленности и торговли, внутренних дел, обороны, иностранных дел, юстиции, а также глава ЦБ, руководитель администрации, генеральный прокурор, директор спецслужбы.

**Персонаж:** имя, возраст, портрет, партия, компетентность, лояльность, взгляды, склонность к коррупции, популярность и 1–2 черты («Технократ», «Популист», «Реформатор», «Силовик», «Харизматичный», «Коррупционер»). Компетентность министра определяет скорость и качество исполнения решений его ведомства. Персонажи стареют, попадают в скандалы, уходят в отставку, переходят в оппозицию. В коалиционном правительстве партнёры получают квоты постов.

**Законы** — около 80 в 11 группах: экономика и собственность, труд, налоги, социальная защита, здравоохранение, образование, гражданские права, безопасность, миграция, экология, выборы и конституция. У каждого закона несколько вариантов (например, минимальная зарплата: нет, низкая, средняя, высокая).

Жизненный цикл закона: подготовка в министерстве (срок зависит от компетентности министра) → голосование в парламенте (партийная дисциплина, взгляды депутатов, лоббирование) → подпись → вступление в силу с переходным периодом → эффект. В данных каждого закона указаны эффекты, отношение классов и групп интересов, стоимость и срок внедрения.

**Силовые структуры:** армия, полиция, национальная гвардия, спецслужба. У каждой — численность, оснащение, финансирование и лояльность. Лояльность падает от недофинансирования, от приказов применять силу против мирных граждан и от непопулярных войн.

**Жёсткие инструменты** доступны в любой системе, но имеют цену: аресты оппозиции, цензура, фальсификация выборов, разгон протестов. Они дают краткосрочный контроль и бьют по легитимности, международным отношениям, радикализации и лояльности силовиков. Модель не прячет эту цену: каждое такое решение видно в статистике и событиях.

## Политика

Политика вырастает из классов: у каждого класса есть взгляды, партии борются за его голоса, группы интересов говорят от его имени. Если запросы класса никто не представляет, появляется новая партия или протест.

**Пространство взглядов — три оси:**

- Экономическая: перераспределение ↔ рынок.
- Гражданская: свободы ↔ порядок.
- Внешняя: открытость миру ↔ суверенитет и национализм.

У каждого класса — распределение взглядов по осям. Оно смещается от обстоятельств: кризис и падение уровня жизни радикализуют, рост и стабильность сдвигают к центру.

**Партии** генерируются для каждой страны: название в местном стиле, позиция на осях, лидер-персонаж, финансирование, организация. Партии раскалываются, объединяются, их запрещают; новая партия появляется, когда у заметной части избирателей нет близкой партии.

**Опросы** — ежемесячно. Каждый класс голосует за партию, ближайшую к его взглядам, с поправками на харизму лидера, компетентность и ответственность власти за экономику: правящую партию наказывают за падение уровня жизни.

**Выборы:**

- Системы: мажоритарная, пропорциональная с барьером, смешанная; президентские — в два тура.
- Кампания за 2–3 месяца: бюджет кампании, поездки и обращения к классам, дебаты (событие с выбором ответов), обещания. Невыполненные обещания потом бьют по доверию.
- Явка зависит от удовлетворённости и радикализма.
- Итоги: карта, полукруг парламента, переговоры о коалиции — посты в правительстве и обещания законов в обмен на поддержку.
- Фальсификация возможна. Риск разоблачения зависит от свободы прессы, наблюдателей и силы оппозиции; разоблачение ведёт к протестам и международной реакции.

**Группы интересов** (как в Victoria 3):

| Группа | Опирается на | Чем давит на власть |
| --- | --- | --- |
| Промышленники | Крупный капитал обрабатывающих отраслей | Инвестиции, финансирование партий |
| Финансисты | Банки, финансы | Кредит, курс, бегство капитала |
| Сырьевое лобби | Добывающие отрасли | Рента, экспорт, деньги на выборы |
| Профсоюзы | Рабочие классы | Забастовки, голоса |
| Аграрии | Крестьяне, фермеры | Протесты, голоса села |
| Силовики | Армия, полиция, спецслужбы | Лояльность, угроза переворота |
| Религиозные организации | Верующие всех классов | Мобилизация, легитимность |
| Интеллигенция | Специалисты, университеты | Медиа, протесты, эмиграция |
| Мелкий бизнес | Предприниматели, самозанятые | Голоса, уход в тень |

У каждой группы — влияние (от силы её классов и политической системы), одобрение власти (от законов и бюджета) и 2–3 текущих требования. Довольная группа поддерживает, недовольная лоббирует против законов, финансирует оппозицию, выводит капитал или бастует.

**Протесты:** вероятность растёт с радикализмом и организованностью класса. Шкала эскалации: забастовка → митинг → массовые протесты → беспорядки → восстание. Ответы власти: уступки, переговоры, игнорирование, разгон — у каждого свои последствия для доверия, радикализма и лояльности силовиков.

**Смена власти без выборов:** вотум недоверия и импичмент в демократиях; дворцовый переворот, военный переворот или революция — когда падают легитимность и лояльность элит. Потеря власти не заканчивает партию: игрок продолжает за новое правительство страны или завершает партию с экраном итогов.

## Внешний мир

Остальные \~189 стран живут по той же модели и управляются ИИ. Дипломатия влияет на торговлю, инвестиции, технологии и безопасность, а значит — на классы внутри страны.

**Отношения** между каждой парой стран (−100…100) складываются из объёма торговли, схожести политических систем и взглядов правящих партий, союзов, споров, помощи и прошлых событий.

**Дипломатические действия:**

| Действие | Что даёт | Цена и риск |
| --- | --- | --- |
| Визит, переговоры | Отношения + | Время главы, внутренняя критика |
| Соглашение о свободной торговле, таможенный союз | Торговля ++, конкуренция для слабых отраслей | Недовольство групп, проигрывающих от импорта |
| Защита инвестиций | Приток иностранного капитала | Ограничения на национализацию |
| Безвизовый режим | Туризм, миграция | Миграционное напряжение |
| Военный союз | Безопасность | Обязательство воевать за союзника |
| Энергетическая сделка | Стабильные поставки или доход | Зависимость |
| Научное сотрудничество | Технологии дешевле | Утечка разработок |
| Помощь и кредиты | Влияние на получателя | Расходы бюджета |
| Санкции и эмбарго | Давление на цель | Потери собственной торговли, ответные санкции |
| Высылка дипломатов | Сигнал недовольства | Отношения −− |

**Международные организации** (вымышленные аналоги): «Совет Наций» голосует по резолюциям, «Международный валютный совет» выдаёт кредиты с условиями, региональные торговые и военные блоки. Членство даёт выгоды и связывает обязательствами.

**Индекс мощи** страны — сводный показатель экономики, армии, технологий и дипломатического влияния; используется в рейтинге и решениях ИИ.

**ИИ стран:**

- У правительства ИИ — взгляды правящей партии, приоритеты (рост, стабильность, сила, переизбрание) и черты лидера.
- Ежемесячно ИИ оценивает варианты по функции полезности: правит бюджет (контроль дефицита, щедрость перед выборами), продвигает законы в рамках своего парламента, ведёт дипломатию (сближение с похожими, санкции против соперников), реагирует на кризисы.
- Все решения ИИ пишутся в журнал отладки с причинами, чтобы находить странное поведение.

**Конфликты** (упрощённо в версии 1):

- Военная сила = численность × оснащение × технологии × боевой дух.
- Война начинается из спора, союзных обязательств или нападения ИИ, если соотношение сил и отношения это допускают.
- Ход войны — помесячная модель истощения с новостями о сражениях. Цена: потери населения, разрушение капитала и инфраструктуры в зоне боёв, расходы, санкции. Поддержка власти сначала растёт («сплочение вокруг флага»), потом падает от усталости.
- Итог — мирный договор: прекращение огня, репарации, торговые или политические уступки. Границы в версии 1 не меняются.

## События и новости

События делают модель живой: они возникают из состояния страны, а не случайно, и предлагают 2–3 решения с разными последствиями. Новости рассказывают, что происходит дома и в мире.

**Движок событий** — данные, а не код: `id`, категория, условия срабатывания (JSON-предикаты по показателям), вес вероятности, перезарядка, варианты с эффектами, продолжение цепочки, персонаж-докладчик, иллюстрация. Категории: экономика, социальная сфера, политика, скандалы, катастрофы, эпидемии, технологии, международные, персонажи. Цель — 30 событий к первому играбельному этапу и 120+ к релизу.

**Примеры, задающие тон:**

| Событие | Когда | Варианты |
| --- | --- | --- |
| Забастовка шахтёров | Зарплаты в добыче отстают от цен | Поднять зарплаты на госшахтах · Третейский суд · Разогнать |
| Обвал цен на нефть | Падение мировой цены, страна — экспортёр | Тратить суверенный фонд · Сократить расходы · Отпустить курс |
| Пузырь на рынке жилья | Быстрый рост ипотеки и цен | Ужесточить кредит · Налог на перепродажу · Ничего не делать |
| Утечка мозгов | Отъезд специалистов растёт | Гранты учёным · Налоговые льготы ИТ · Ограничить выезд (свободы −) |
| Новая инфекция | Случайно, чаще при слабой медицине | Карантин (экономика −, смертность −) · Массовая вакцинация (нужны фармацевтика или импорт) · Минимальные меры |
| Землетрясение или наводнение | Случайно по сейсмике и климату страны | Восстановление из бюджета · Международная помощь (отношения +, долг влияния) |
| Засуха | Аграрная страна, климат | Импорт зерна · Субсидии фермерам · Ограничить экспорт |
| Скандал с министром | Министр-коррупционер, свободная пресса | Уволить (популярность +, лояльность элит −) · Защищать · Независимое расследование |
| Ультиматум министра | Ведомство недофинансировано | Дать денег · Принять отставку · Найти компромисс |
| Банк на грани краха | Риск банковского кризиса | Спасти · Национализировать · Дать рухнуть |
| Протест против роста тарифов | Повышение коммунальных тарифов | Отменить · Адресная помощь бедным · Разогнать |
| Иностранный завод | Хороший деловой климат | Налоговые льготы · Требование локализации · Отказ |
| Пошлины соседа | Торговый спор | Зеркальные пошлины · Переговоры · Жалоба в организацию |
| Роботизация | Технология автоматизации освоена | Программы переобучения · Налог на роботов · Ничего |
| Демографический спад | Рождаемость ниже 1,5 | Семейные выплаты · Жильё для семей · Ставка на миграцию |

**Новости:**

- Лента внизу экрана: дома и в мире, по шаблонам из модели («Безработица в стране выросла до 8,4%»).
- Телевыпуск раз в неделю: ведущий-персонаж с портретом, 3–5 главных сюжетов голосом.
- Газета раз в месяц: первая полоса с заголовком месяца и тремя материалами, тон издания зависит от его владельца и свободы прессы.
- Доклады министров: министр с портретом приносит проблему и рекомендацию; рекомендация зависит от его взглядов и компетентности, поэтому иногда она плохая.

## Интерфейс и графика

Стиль — современный кабинет правительства: тёмно-графитовые панели, один сдержанный акцентный цвет, чёткая типографика и много хорошо читаемых графиков. Глубина модели бесполезна, если её не видно, поэтому у любого показателя есть всплывающая подсказка «почему»: из чего он сложился и что на него влияет (как в Victoria 3).

**Карта мира:**

- Границы Natural Earth и растровая подложка с рельефом Natural Earth (общественное достояние); города — из набора населённых пунктов Natural Earth.
- Масштаб от мира до страны с подписями городов.
- Режимы карты: политическая, ВВП на душу, рост, безработица, инфляция, долг, уровень жизни, одобрение власти, отношения с вашей страной, союзы и блоки, торговые потоки (анимированные линии), демократия, энергобаланс, войны.
- Анимации: импульсы новостей на точке события, линии торговли, мерцающая зона боевых действий.
- 3D-глобус — позже, в версии 2.

**Экраны:**

| Экран | Содержание |
| --- | --- |
| Главный | Карта; верхняя панель с датой, скоростью и ключевыми показателями (рост, инфляция, безработица, бюджет, одобрение); слева — иконки ведомств; внизу — лента новостей; справа — уведомления |
| Ведомство (по одному на министерство) | Показатели с графиками за 10 лет, бюджет, программы, законы, министр с портретом и докладом |
| Бюджет и налоги | Все статьи с ползунками и прогнозом влияния на классы |
| Законы | Каталог, статусы, ход голосования, кто за и кто против |
| Общество | Классы: численность, доходы, уровень жизни, удовлетворённость, взгляды; группы интересов и их требования |
| Политика | Опросы, партии, парламент полукругом, кампания и выборы |
| Дипломатия | Досье страны, отношения, договоры, организации |
| Наука | Дерево технологий и распределение очков |
| Инфраструктура | Объекты, загрузка, стройки |
| Статистика | Любой показатель, сравнение стран, рейтинги |
| Персонажи | Правительство, оппозиция, лидеры других стран |

Интерфейс масштабируется от 1080p до 4K; у основных экранов есть горячие клавиши; открытое важное событие ставит игру на паузу.

**Шрифты** (OFL, с кириллицей): IBM Plex Sans для интерфейса и цифр, PT Serif для заголовков документов и газеты. Лицензии — в `LICENSES-ASSETS.md`.

**Портреты персонажей** — пул из 200–300 вымышленных лиц, который пользователь генерирует в Grok по списку промптов (как в ТЗ «Призрак»):

- Claude Code формирует `PORTRAITS.md`: регион мира, пол, возрастная группа, роль (политик, военный, ведущий, учёный) и промпт.
- Единый стиль: полуреалистичная цифровая живопись, официальный портрет по пояс, нейтральный фон. В промпте указано, что человек вымышленный и не похож на реальных людей.
- Скрипт обработки обрезает до 3:4, выравнивает цвет и проставляет теги. Персонаж получает портрет по региону, полу и возрасту.
- Иллюстрации для крупных событий (\~50) — тем же способом. Пока картинок нет, работают заглушки-силуэты.
- В титрах — строка «Портреты и иллюстрации созданы с помощью Grok».

**Озвучка:**

- Встроенный синтез речи Godot (системные голоса Windows) — для новостей и докладов с переменным текстом. Включается в настройках; если русского голоса в системе нет, игра подскажет, как его установить.
- Заранее записанные фразы для постоянных реплик: приветствия министров, заставка телевыпуска, реакции на крупные события. Их генерирует офлайн-синтезатор речи; исполнитель выбирает голоса, чья лицензия разрешает использование в игре, и записывает её в `LICENSES-ASSETS.md`. Альтернатива — голоса, которые пользователь сгенерирует в сервисе синтеза речи с подходящими условиями.
- Разные голоса для ведущего и для министров разного пола.

**Музыка и звуки:** спокойные эмбиент-треки CC0 или CC BY с указанием автора; темы для кризиса, войны и ночи выборов меняются по обстановке. Звуки: щелчки интерфейса, уведомления, гул толпы на протестах, аплодисменты в парламенте, печатная машинка для документов.

## Этапы и критерии приёмки

Десять этапов; это многомесячный проект, и каждый этап занимает несколько сессий Claude Code. После каждого этапа — сборка в Releases и проверка пользователем. Ранние этапы дают «аквариум»: мир, который живёт и которым можно немного управлять. Полноценная игра появляется к этапу 7.

0. **Каркас.** Решение C#, проект Godot, CI, сборка данных мира, карта с режимами, панель страны.
   - Windows-версия из Releases запускается; карта идёт в 60 кадрах/с; данные 190 стран загружены; у показателей есть всплывающие подсказки.
1. **Экономика и финансы.** Отрасли, рынок труда, цены, инфляция, ЦБ, бюджет, долг, торговля, разогрев.
   - Прогон без графики на 50 лет: мировой рост в среднем 1–5% в год, нет бесконечных значений и ошибок; после разогрева показатели отличаются от стартовых не больше чем на 10%.
2. **Население и классы.** Демография, классы, потребности, уровень жизни, удовлетворённость, мобильность.
   - Население 10 крупнейших стран к 2050 году в пределах ±15% от прогноза ООН.
3. **Власть и законы.** Политические системы, правительство и министры (портреты-заглушки), первые 40 законов, экраны ведомств, бюджетный цикл через парламент.
   - Закон проходит весь цикл; провал бюджета в парламенте отрабатывается корректно.
4. **Политика.** Оси взглядов, партии, опросы, выборы и кампании, коалиции, группы интересов, протесты, перевороты.
   - В рецессию рейтинг правящей партии падает; выборы дают правдоподобные результаты.
5. **Социальная сфера, инфраструктура, энергетика, наука.**
   - Рост расходов на образование меняет квалификацию работников с задержкой в годы; дефицит электричества режет выпуск.
6. **Внешний мир.** Дипломатия, ИИ стран, организации, санкции, упрощённые войны.
   - Без игрока за 50 лет не меньше 90% стран не впадают в коллапс; ИИ ведёт себя объяснимо по журналу решений.
7. **События и новости.** Движок событий, 30 событий и далее до 120, лента, телевыпуск, газета, доклады министров.
   - За игровой год игрок видит 10–20 разных событий, связанных с состоянием страны.
8. **Графика и звук.** Портреты и иллюстрации из Grok, озвучка, музыка, анимации, обучение.
   - Все портреты в едином стиле; озвучка работает без интернета.
9. **Баланс и сценарии.** Набор проверок правдоподобия, сценарии с целями, сохранения, итоговая полировка.
   - Набор проверок из `Politeconomy.Tools` проходит; сценарии проходимы и не проходятся «сами».

## Указания для Claude Code

Этот документ лежит в корне репозитория как `SPEC.md`. Первая команда — «Прочитай SPEC.md целиком и выполни этап 0»; дальше по одному этапу, а внутри большого этапа — по одной подсистеме за сессию.

**Порядок работы:**

- Перед этапом — короткий план и список файлов. После — коммит, тег `v0.<этап>.<n>`, запись в `CHANGELOG.md` и пошаговая инструкция, что проверить в игре.
- `MODEL.md` — живое описание модели: каждая формула, порядок систем, смысл коэффициентов. Обновлять вместе с кодом: это память проекта между сессиями.
- Неясная деталь — выбрать простейший правдоподобный вариант, записать в `DECISIONS.md` и продолжать. Пользователя спрашивать о дизайне и вкусе, а не о технике.
- Пользователь — не программист: инструкции писать по шагам, без жаргона.

**Код и данные:**

- `Politeconomy.Sim` не зависит от Godot; файлы короткие, по одной системе на файл.
- Весь контент — в `data/*.json` со схемами в `data/README.md`; `Politeconomy.Tools validate` проверяет ссылки и диапазоны и запускается в CI.
- Условия событий и эффекты законов — данные, не код.
- Все коэффициенты модели — в `data/balance.json` с комментариями в `MODEL.md`.
- Политиков и партий из реального мира нет; имена генерируются из `data/names/*.json` по культурам.

**Тесты (xUnit) и проверки правдоподобия:**

- Тождества национальных счетов: ВВП = потребление + инвестиции + госрасходы + чистый экспорт (с допуском); бюджет сходится; деньги не появляются из ниоткуда.
- Демографический баланс: население прошлого месяца + рождения − смерти ± миграция.
- Детерминизм: одинаковый seed — одинаковая партия.
- Сохранение → загрузка дают то же состояние.
- Жизненный цикл закона, подсчёт голосов на выборах, условия событий.
- `Politeconomy.Tools check` — прогон мира на 50 лет и проверка диапазонов: рост, инфляция, безработица, долг, население. Отчёт сохраняется в CI.

**Настройка (делает пользователь):** приватный репозиторий `politeconomy` на GitHub, доступ Claude Code только к нему, `SPEC.md` в корне. Готовые сборки скачиваются из Releases. По желанию можно поставить на ПК Godot (.NET) и открывать проект напрямую — так быстрее смотреть изменения интерфейса. Портреты и иллюстрации — по `PORTRAITS.md` в папку `art/incoming/`.
