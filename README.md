# Politeconomy

Глобальный политико-экономический симулятор для ПК. Вы управляете одной из 198 стран: экономикой, бюджетом, законами, выборами, дипломатией и войной за регионы. Остальными странами управляет компьютер. Полное техническое задание — в [SPEC.md](SPEC.md).

**Сейчас готова первая версия этапа 1 «Экономика и финансы»:** карта мира из 2286 регионов и 7 тыс. городов, досье каждой страны с реальными данными на начало 2026 года и живая экономика — 20 отраслей, инфляция, центробанки и курсы валют, бюджет, госдолг, рейтинги и дефолты. Население, политика и законы появятся на следующих этапах; пока бюджетами всех стран управляет автопилот.

## Как скачать и запустить

1. Откройте на GitHub вкладку **Releases** и скачайте архив `Politeconomy-v…-windows.zip` последней версии.
   Если релиза ещё нет: вкладка **Actions** → последний зелёный запуск «Сборка» → внизу страницы файл **Politeconomy-windows**.
2. Распакуйте архив **целиком** в любую папку. Рядом с `Politeconomy.exe` должна лежать папка `data` — без неё игра не запустится.
3. Запустите `Politeconomy.exe`.

При первом запуске Windows может показать синее окно SmartScreen «Windows защитила ваш компьютер». Так бывает с любыми программами без платной цифровой подписи. Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.

Нужна Windows 10 или 11 (64-bit). Если видеокарта старая и игра не открывается, она сама переключится на упрощённый режим графики.

## Управление

| Действие | Как |
| --- | --- |
| Сдвинуть карту | Перетащить мышью или клавиши W A S D / стрелки |
| Приблизить или отдалить | Колесо мыши или клавиши + и − |
| Показать весь мир | Home |
| Открыть досье страны и регион | Щелчок по региону на карте или по названию в списке регионов в досье |
| Закрыть досье | Esc или × |
| Пауза | Пробел или кнопка ▶ в верхней панели |
| Скорость времени 1–5 | Клавиши 1–5 или кнопки в верхней панели |
| Режимы карты | F1–F12 или кнопки в левом нижнем углу |

Наведите курсор на любой показатель — подсказка расскажет, откуда взято число и за какой год, а для показателей, которые считает модель, — из чего складывается значение. Значок «≈» означает оценку: по этой стране в источниках не нашлось данных, и игра взяла медиану по похожим странам.

## Что внутри

| Папка | Что там |
| --- | --- |
| `src/Politeconomy.Sim` | Модель мира на C#, без графики. Её можно гонять на 50 лет вперёд и тестировать |
| `src/Politeconomy.Sim.Tests` | Автоматические тесты |
| `src/Politeconomy.Tools` | Консольные проверки: `validate` (данные), `check` (прогон на 50 лет с проверками правдоподобия), `report` (таблица по странам), `trace` (помесячная трассировка страны) |
| `game/` | Проект Godot 4.7: карта, интерфейс, звук |
| `data/` | Весь контент в открытых JSON-файлах — его можно менять (моды) |
| `tools/` | Скрипт сборки данных мира из открытых источников |

Документы проекта: [MODEL.md](MODEL.md) — как устроена модель, [DECISIONS.md](DECISIONS.md) — принятые решения, [CHANGELOG.md](CHANGELOG.md) — что изменилось в каждой версии, [LICENSES-ASSETS.md](LICENSES-ASSETS.md) — источники данных, шрифты и их лицензии.

## Для разработки

- Проект Godot: установите Godot 4.7.2 **.NET** и .NET SDK 8, откройте `game/project.godot`.
- Тесты: `dotnet test Politeconomy.sln`.
- Проверка данных: `dotnet run --project src/Politeconomy.Tools -- validate`.
- Прогон мира: `dotnet run --project src/Politeconomy.Tools -- check` (50 лет), `-- trace --country RUS --years 5` (одна страна по месяцам).
- Свежие данные МВФ, Всемирного банка, BIS и GeoNames: workflow «Источники данных» в GitHub Actions (запускается при изменении `tools/fetch_sources.py`) сохраняет их в `tools/sources/`.
- Пересборка данных мира: `pip install -r tools/requirements.txt`, `npm install --prefix tools`, затем `python tools/build_world.py`.
