# Данные игры

Весь контент лежит здесь в открытых JSON-файлах. Игра читает их при запуске из папки `data` рядом с `Politeconomy.exe`, поэтому их можно менять — это основа для модов. После правки проверьте данные:

```
dotnet run --project src/Politeconomy.Tools -- validate
```

Файлы `countries.json`, `regions.json`, `map/world.json` и `map/cities.json` собирает скрипт `tools/build_world.py` из снимков источников в `tools/sources/` (МВФ, Всемирный банк, BIS, GeoNames). Остальные файлы ведутся вручную.

## countries.json

Страны — члены ООН и их стартовые показатели.

| Поле | Что это |
| --- | --- |
| `id` | Код ISO 3166-1 alpha-3, например `RUS` |
| `iso2` | Двухбуквенный код |
| `name`, `short_name`, `official_name`, `name_en` | Название, короткое название для карты, официальное, английское |
| `capital`, `region`, `subregion` | Столица и регион мира по-русски |
| `area_km2`, `landlocked` | Площадь, нет ли выхода к морю |
| `income_group` | `low`, `lower_middle`, `upper_middle`, `high` |
| `income_source` | Откуда взята группа дохода |
| `stats` | Показатели: `{ "<id показателя>": { "value", "year", "source", "method"?, "n"? } }` |
| `un_member`, `status_note` | Член ли ООН; для остальных — пояснение статуса |
| `currency` | Код валюты ISO 4217 (`RUB`, `EUR`…), см. `currencies.json` |

`source`: `wb:<код Всемирного банка>`, `imf:<код МВФ>`, `bis:WS_CBPOL` (ключевые ставки ЦБ), `natural_earth`, `fill` (медиана по похожим странам, `method` — как именно, `n` — сколько стран в выборке) или `derived` (вычислено, `method` — формула).

## regions.json

Регионы стран: `id` (код административной единицы Natural Earth), `name`, `country` (владелец по международному праву), `capital` (главный город), `population`, `population_source` (`geonames` или `estimate`), `area_km2`, `units` (сколько единиц Natural Earth объединено).

## control.json

Стартовый контроль регионов, если он отличается от принадлежности: `control[]` — `region`, `controller` (кто фактически контролирует), `note`. Пусто — везде контролирует владелец.

## indicators.json

Описание показателей: `id`, `name` (как называется в игре), `format`, `description` (текст подсказки), `unit` (необязательно).

Форматы: `people` (143,5 млн), `money_big` (2,56 трлн $), `money` (17 850 $), `percent` (8,7%), `percent_signed` (+2,2%), `percent_gdp` (17,9% ВВП), `percent_gdp_signed` (−7,9% ВВП), `years` (73,2 года), `number0`, `number1`, `number2`, `number1_signed` (+2,5), `rating` (балл 0–21 выводится буквами: 21 — AAA, 13 — BBB, 0 — D).

## politics.json

`systems` — названия типов политических систем, `regimes` — названия режимов. `countries` — для каждой страны: `id`, `system` (тип), `regime` (`democracy` — свободные выборы, `hybrid` — выборы с перекосом в пользу власти, `authoritarian` — выборы формальны или их нет), `electoral` (избирательная система парламента: `majoritarian` — побеждает первый в округе, `proportional` — по спискам, `mixed` — половина мест так, половина так, `none` — выборов нет), `threshold` (барьер для пропорциональной части, % голосов), `parties` (есть ли легальные партии), `ruling_family` (особое семейство партии власти — у коммунистических однопартийных государств), `term` (срок парламента, лет), `next_election` (ближайшие выборы парламента, «год-месяц»; если нет — игра выберет дату в пределах срока), у президентских и смешанных республик — `president_term`, `next_president`, `two_rounds` (второй тур, если никто не набрал больше половины), `note` (особенность), `reviewed` (проверено ли человеком).

Типы: `presidential_republic`, `parliamentary_republic`, `semi_presidential`, `constitutional_monarchy`, `absolute_monarchy`, `one_party_state`, `military_regime`.

## scenario.json

`id`, `name`, `description`, `start_date` (ГГГГ-ММ-ДД), `seed` (число для генератора случайностей), `warmup_months` (сколько месяцев модель скрыто прогоняется перед стартом, с этапа 1), `player_country` (код страны или `null` — выбрать на карте).

## balance.json

Коэффициенты модели; смысл каждого — в `MODEL.md`. `time.days_per_second` — пять скоростей времени, игровых дней в секунду. `demography` — коэффициенты населения (MODEL.md, «Демография»). `society` — коэффициенты классов: состав, доходы, корзины потребностей, настроение, влияние (MODEL.md, «Классы»). `government` — коэффициенты персонажей, отставок и парламента (MODEL.md, «Правительство»). `laws` — коэффициенты законов и индексов институтов (MODEL.md, «Законы» и «Институты»). `budget_cycle` — бюджетный процесс страны игрока: месяцы проекта и голосований, отношение классов к бюджету, пределы ползунков (MODEL.md, «Бюджетный цикл»). `politics` — взгляды, партии, опросы и выборы: сдвиги взглядов стран, привлекательность партий, экономическое голосование, усталость от власти, число партий, распределение мест, коалиции, явка, итоги по регионам, переговоры (MODEL.md, «Взгляды», «Партии», «Опросы», «Выборы»). `economy` — коэффициенты экономики по разделам: `supply` (потенциальный рост), `demand` (цикл, инвестиции, торговля), `labor`, `prices`, `monetary`, `exchange`, `commodities`, `budget` (долг, бюджетное правило, дефолт), `rating`. Списки из четырёх чисел — по группам дохода: низкий, ниже среднего, выше среднего, высокий. Если коэффициент убрать, модель возьмёт значение по умолчанию (оно совпадает с файлом).

## population.json

Собирается `tools/build_world.py`. `groups` — подписи 17 возрастных групп. `countries[]`: `id`, `year`, `female` и `male` — численность по группам 0–4 … 75–79, 80+ (сумма равна населению страны), `fertility` (детей на женщину), `adolescent_fertility` (рождений на 1000 женщин 15–19 лет), `life_expectancy_female` и `life_expectancy_male`, `infant_mortality` (на 1000 родившихся), `net_migration` (человек в год, среднее за 2015–2025), `urban_pct`, `urban_change` (п. п. в год), `path` — прогноз по годам: `years`, `fertility`, `life_expectancy` (может отсутствовать).

## history.json

Собирается `tools/build_world.py` из тех же снимков Всемирного банка и МВФ, что и `countries.json`. История показателей до старта игры для графиков ведомств: `first_year` и `last_year` (2016–2025), `countries` — для каждой страны показатель → значения по годам (`null` — данных за год нет). Ключи показателей — из `indicators.json`. Дальше историю пишет модель (MODEL.md, «История показателей»).

## parties.json

Партии (MODEL.md, «Партии»). `axes` — три оси взглядов: `id`, `name`, что значит минус (`low`) и плюс (`high`). `families[]` — семейства партий: `id`, `name`, `position` (три числа −100…100 — позиция для страны со средними взглядами), `color`, `weight` (вес при выборе семейства), `by_income` (множитель веса по группам дохода, необязательно), части названия: `adjectives` (прилагательные в мужском, женском и среднем роде), `tails` (хвосты в родительном падеже: «партия труда»), `quoted` (названия в кавычках). `power` — партия власти несвободных режимов в том же формате; её `position` — сдвиг от средних взглядов страны. `nouns[]` — слова «партия», «союз», «фронт»…: `word`, `gender` (`m`, `f`, `n`), `weight`, `regions` (множитель по части света, необязательно).

## government.json

`systems[]` — для каждого типа политической системы: `id`, `leader` (как называется глава исполнительной власти — это игрок), `parliament` (`real` — голосует всерьёз, `formal` — одобряет почти всё, `none` — власть правит указами), `parliament_name`. Авторитарный режим делает любой парламент формальным. `leader_titles` — особые названия главы для стран (Германия — «Федеральный канцлер»). `posts[]` — 18 постов правительства: `id`, `name` (должность), `ministry` (ведомство), `short` (подпись на карточке), `spending` (статьи бюджета ведомства из `budget.json`), `security` (силовой пост), `finance` (экономический пост), `stats` (до четырёх показателей из `indicators.json` для графиков и доклада на экране «Ведомства»). `traits[]` — черты персонажей: `id`, `name`, `description`, прибавки `competence`, `loyalty`, `corruption`, `popularity` и `weight` (как часто встречается). `parliament_seats` — число мест в парламенте для стран, где оно известно.

## laws.json

`groups[]` — 11 групп законов (`id`, `name`). `effects` — что означает каждый эффект: `name`, `unit` («п. п.», «доля», «% ВВП», «лет», «пункты»), `description`; validate проверяет, что модель умеет применять каждый эффект. `laws[]` — законы: `id`, `group`, `name`, `post` (какое ведомство готовит закон — id поста из `government.json`), `description`, `drafting_months` (подготовка при средней компетентности министра), `transition_months` (за сколько месяцев эффект набирает силу), `constitutional` (нужно две трети парламента), `variants[]` (`id`, `name`, `description`, `effects` — словарь «эффект — значение», `attitudes` — отношение классов от −3 до +3), `start` — вариант на старте: `default`, затем `income` (по группе дохода), `system` (по типу системы), `regime` (по режиму), `countries` (по стране); более частное правило побеждает. Эффект закона в игре — разница между нынешним вариантом и вариантом на старте.

## names/*.json

Культура имён, по одной на файл: `id`, `name`, `order` (`given_family` — «Иван Петров», `family_given` — «Ван Лэй»), `countries` (у каждой страны ровно одна культура), `male`, `female` (имена), `surnames` (фамилии в мужской форме), `feminine` — правила женской формы фамилии: пары «окончание — замена» (`["ов", "ова"]`), берётся самое длинное подходящее окончание. Все имена — русскими буквами.

## classes.json

`classes[]` — десять классов в фиксированном порядке (безработные, неквалифицированные рабочие, квалифицированные рабочие, крестьяне и фермеры, служащие, специалисты, мелкий бизнес, крупный капитал, госаппарат и силовики, пенсионеры): `id`, `name`, `short_name` (необязательно: название в таблице досье, если полное не помещается), `income` (источник дохода — для подсказки), `interests` (главные интересы), `organization` (организованность 0–1: профсоюзы, ассоциации, связи), `radicalism` (радикализм в спокойное время, 0–100), `saving` (доля дохода, которую класс откладывает), `property` (доля в дивидендах, процентах и аренде на человека относительно рабочего), `job_risk` (насколько класс боится роста безработицы), `inflation` (насколько остро чувствует инфляцию, 1 — как все), `color` (цвет в интерфейсе), `views` (средние взгляды класса по трём осям из `parties.json`, от −100 до 100, для страны со средним доходом), `turnout` (обычная явка класса на выборах, 0–1). Численность и доходы считает модель.

## benchmarks/population.json

Ориентиры для проверок `check` и тестов, в игре не используются: `population` — прогноз ООН по странам и годам (2025, 2030 … 2050).

## currencies.json

`currencies[]` — валюты, у которых есть особенности: `id` (код ISO 4217), `name`, `regime` (`float` — плавающий курс и своя ставка; `peg` — курс привязан к валюте `anchor`, ставка следует за ней), `reserve` (резервная валюта: выше рейтинг), `bank` (общий центробанк, если валютой пользуются несколько стран). Валюта, которой нет в файле, — плавающая. Якорь привязки сам должен быть плавающим.

## industries.json

`industries[]` — 20 отраслей: `id`, `name`, `sector` (`agriculture`, `industry`, `services` — часть ВВП по Всемирному банку), `kind` (`commodity`, `manufactured`, `service`, `public`), `cycle` (во сколько раз сильнее среднего отрасль качается в подъём и спад), `alpha` (доля капитала в доходе), `depreciation` (выбытие капитала в год), `skills` (доли работников без образования, с профессиональным и высшим — с этапа 2), `manufacturing_share` (доля в обрабатывающей промышленности по группам дохода; сумма по отраслям — 1), `services_share` (доля в услугах), `market_service` (рыночная услуга: торговля, транспорт, финансы, ИТ). Отрасли `agriculture`, `oil_gas`, `coal_ores`, `defense`, `construction`, `tourism` обязательны — по ним идёт калибровка.

## budget.json

- `revenues[]` — статьи доходов: `id`, `name`, `base` (`wages`, `profits`, `consumption`, `imports`, `resources`, `assets`, `gdp` — от чего считается сбор), `elasticity` (во сколько раз сильнее ВВП сбор реагирует на подъём и спад), `shares` (доля в доходах по группам дохода; сумма по статьям — 1; рента считается отдельно по добыче).
- `spending[]` — статьи расходов: `id`, `name`, `shares` (доля в расходах без процентов; сумма — 1; оборона берётся из данных о военных расходах), `supporters` (классы, которые выигрывают от статьи и следят за ней при голосовании о бюджете). Обслуживание долга считается по долгу и ставке.

## map_modes.json

- `palettes` — цвета в формате `#rrggbb`: `political` (8 цветов политической карты), `sequential` (шкала от меньшего к большему), `diverging_negative` / `diverging_neutral` / `diverging_positive` (две стороны от нуля, от сильного к слабому и от слабого к сильному), `no_data`, `territory`.
- `modes` — режимы карты: `id`, `name`, `short_name` (подпись кнопки), `kind`, `indicator`, `thresholds` (пороги классов по возрастанию), `hotkey`.
  - `political` — каждая страна своим цветом, соседи различаются.
  - `bins` — классы по порогам, цвета из `sequential`. Классов на один больше, чем порогов.
  - `diverging` — классы по порогам вокруг нуля; число порогов чётное и вдвое больше длины каждого плеча палитры.
  - `politics`, `income` — категории, цвета из `politics_colors` и `income_groups`.
  - `region_density` — плотность населения каждого региона по порогам, `unit` — подпись единиц в легенде.
  - Регион окрашивается по стране, которая его контролирует.

## map/world.json

Геометрия карты в проекции Equal Earth (ширина 8192, ось y вниз).

- `regions[]`: `id`, `country` (владелец) или `territory` (нейтральная территория), `label` (точка подписи `[x, y]`), `polygons[]` — `rings` (внешнее кольцо и дыры, координаты подряд `x0, y0, x1, y1, …`) и `triangles` (индексы вершин, по три на треугольник).
- `countries[]`: `id`, `label`, `color` (номер цвета политической карты), `neighbors` (соседи по суше), `outline` (контур страны для подсветки).
- `territories[]`: нейтральные территории — `id`, `name`, `note`, `label`.
- `lines`: `coast` (побережье), `border` (границы стран), `internal` (границы регионов) — ломаные, координаты подряд.

## map/cities.json

`cities[]`: `name`, `country`, `region`, `x`, `y` (в координатах карты), `population`, `capital` (столица страны), `regional_capital` (центр региона), `rank` (0 — столица, 1 — от миллиона, 2 — от 250 тыс., 3 — остальные). В список входят столицы стран и регионов, города от 100 тыс. жителей и главный город каждого региона.
